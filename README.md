# Cybersecurity-home-lab
My beginner cybersecurity home lab using VirtualBox, Ubuntu, Kali Linux, Apache, and network scanning.
Project Overview

This is my beginner cybersecurity home lab, built to develop practical skills in Linux, networking, web servers, network scanning, and security monitoring.

Lab Environment

* Host machine: MacBook
* Virtualization: VirtualBox
* Attacker / testing machine: Kali Linux
* Target machine: Ubuntu Linux
* Web server: Apache2
* Network configuration: Host-only network between the virtual machines

Lab Network

Machine	IP Address	Purpose
Ubuntu	192.168.56.2	Target machine and Apache web server
Kali Linux	192.168.56.3	Security testing machine

These IP addresses belong to my isolated virtual lab network.
