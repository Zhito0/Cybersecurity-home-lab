Exercise 12: Web Application API Endpoint Discovery

Objective

Observe API-related network requests generated by OWASP Juice Shop during normal product-search activity.

Lab Environment

* Testing machine: Kali Linux
* Target machine: Ubuntu Linux
* Application: OWASP Juice Shop
* Target address: http://192.168.56.2:3000

Procedure

1. Opened OWASP Juice Shop in Firefox on Kali Linux.
2. Opened Developer Tools and selected the Network tab.
3. Selected the Fetch/XHR filter.
4. Searched for APPLE using the application’s search feature.
5. Observed the search results and inspected the resulting network requests.

Observations

* The application displayed matching products, including Apple Juice, Apple Pomace, and Pineapple Juice.
* The browser address bar showed the client-side route /#/search?q=APPLE.
* The Network panel displayed requests including search?q= and /api/Quantities/.
* The selected search request showed HTTP status 304 Not Modified.
* The response details showed HTTP version HTTP/1.1.
* Other requests in the Network panel returned HTTP status 200.

Analysis

The search feature worked as expected and displayed matching products.

The client-side route in the browser address bar is distinct from the HTTP request displayed in the Network panel. Inspecting both helps illustrate how a web application’s front end and backend interact.

An HTTP 304 Not Modified response indicates cache validation and does not, by itself, indicate an error. The observed 200 responses indicate successful HTTP requests.

Security Considerations

* Testing was limited to the intentionally vulnerable Juice Shop application in my home lab.
* Only normal application functionality and network traffic were observed.
* No exploitation or request manipulation was performed.
* The application remains restricted to the isolated lab network.

Conclusion

Successfully observed application requests generated during product searching and identified API-related request paths using Firefox Developer Tools. This exercise introduced browser-based API discovery and HTTP response analysis.
